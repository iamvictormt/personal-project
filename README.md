# Victor Torres — Design Studio & Portfolio

Portfólio interativo de Victor Torres, Engenheiro de Software e Desenvolvedor Full Stack.

Construído com **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS v4** e **TypeScript**.

## Tecnologias

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **UI & Estilização:** [Tailwind CSS v4](https://tailwindcss.com/) com paleta OKLCH
- **Componentes:** Baseados em [Radix UI](https://www.radix-ui.com/) e [shadcn/ui](https://ui.shadcn.com/)
- **Ícones:** [Lucide Icons](https://lucide.dev/)
- **Tipografia:** Google Fonts (`Archivo` e `Space Grotesk`) via `next/font`

## Como Executar Localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) (v18.18+ ou v20+)
- npm

### Instalação

```sh
git clone <url-do-repositorio>
cd victor-torres-dev
npm install
```

### Desenvolvimento

```sh
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.

### Build de Produção

```sh
npm run build
npm run start
```
